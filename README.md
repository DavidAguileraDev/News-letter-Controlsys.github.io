## 📌 Descripción

Este repositorio contiene una firma de correo electrónico desarrollada para **Controlsys**, diseñada para integrarse en Outlook y mantener una presentación visual coherente con la identidad corporativa de la empresa.

El proyecto utiliza HTML y CSS para estructurar el contenido y controlar su apariencia en clientes de correo electrónico.

## ✨ Características

- Diseño adaptado a la identidad corporativa de Controlsys.
- Estructura basada en tablas HTML para favorecer la compatibilidad con Outlook.
- Estilos CSS en línea para mejorar la consistencia visual.
- Logotipos e imágenes integrados en el diseño.
- Enlaces a la web corporativa y a redes sociales.
- Contenido organizado en diferentes secciones.

## 🛠️ Tecnologías utilizadas

- **HTML5:** estructura y organización del contenido.
- **CSS:** estilos, colores, espaciado y presentación visual.
- **Tablas HTML:** distribución de los elementos para mejorar la compatibilidad con clientes de correo.

## 🚀 Uso

1. Clona o descarga el repositorio.
2. Abre el archivo `index.html` en un navegador para visualizar el diseño.
3. Modifica el contenido HTML si necesitas adaptar los textos, imágenes o enlaces.
4. Comprueba el resultado en Outlook antes de utilizar la firma.

## 📝 Consideraciones

- El diseño de los correos electrónicos puede variar según el cliente y su versión.
- Las imágenes deben estar disponibles mediante rutas accesibles para que se visualicen correctamente.
- Es recomendable comprobar la compatibilidad de la firma en Outlook antes de distribuirla.
